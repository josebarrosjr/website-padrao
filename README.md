# Website padrão

Modelo de site institucional estático em HTML, CSS e JavaScript, com conteúdo de exemplo `Lorem Ipsum`.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `css/style.css`: identidade visual, componentes e regras responsivas.
- `js/main.js`: menu mobile, ano do rodapé e validação demonstrativa do formulário.
- `assets/images/`: imagens de exemplo e assinatura do rodapé.
- `fonts/`: fonte local usada pelo modelo.

## Executar localmente

Não há dependências para instalar nem etapa de build. Na raiz do projeto, execute:

```bash
python -m http.server 8000
```

Abra `http://localhost:8000` no navegador.

Não há testes automatizados ou comandos de lint configurados neste projeto.
